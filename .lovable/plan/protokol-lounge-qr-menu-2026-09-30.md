# Protokol Lounge QR Menu

## Build
- Replace the blank home screen with a mobile-first dark charcoal and gold menu experience.
- Feature the supplied gold PL monogram in a refined opening section with subtle motion.
- Add a sticky, horizontally scrollable category bar with smooth section navigation and active-category feedback.
- Render every supplied category and item from structured menu data, with polished imagery, descriptions/options, and `₺ --` price tags.
- Use a small cohesive set of premium food and drink images across related menu entries so every card has a visual without relying on unstable external image links.

## Design
- Luxury lounge direction: deep black surfaces, bronze-gold accents, restrained glass effects, Playfair Display headings, and Inter body text.
- Compact mobile cards with stable image proportions; responsive two-column presentation on larger screens.
- Smooth reveal and logo motion with reduced-motion support.

## Validation
- Confirm metadata, mobile and desktop layouts, sticky navigation, smooth scrolling, image loading, and current preview build health.
